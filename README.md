#  Car Price Prediction using Machine Learning

##  Project Overview
This project predicts the selling price of cars based on various features such as fuel type, transmission, and year using Machine Learning.

##  Objective
To build a model that can accurately predict car prices using historical data.

##  Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

##  Dataset
The dataset contains details like:
- Car Name
- Year
- Selling Price
- Present Price
- Fuel Type
- Seller Type
- Transmission
- Owner

##  Steps Involved
1. Data Collection  
2. Data Cleaning & Preprocessing  
3. Feature Selection  
4. Model Training (Linear Regression)  
5. Model Evaluation  
6. Visualization  

##  Model Used
- Linear Regression

##  Output
- R² Score: ~0.84 (Good Accuracy)
- Graph showing Actual vs Predicted Prices
